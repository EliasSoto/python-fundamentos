# 🐍 Python Fundamentos

> *Repositorio de estudio y práctica de los fundamentos de **Python**.*

> [!NOTE]
> Los ejercicios desarrollados en este repositorio están construidos bajo mi propia lógica y razonamiento. Aunque algunos algoritmos pueden tener implementaciones más eficientes, el objetivo principal es comprender la lógica detrás de cada problema y el proceso necesario para construir algoritmos desde cero.

---

## 📚 Contenidos

| 📌 Tema            | 📝 Contenido                                            |
| :----------------- | :------------------------------------------------------ |
| 🟦 `control_flujo` | Condicionales, ciclos y estructuras de control          |
| 🟩 `funciones`     | Creación, parámetros, retorno y reutilización           |
| 🟨 `listas`        | Manipulación y recorrido de listas                      |
| 🟧 `matrices`      | Manipulación y recorrido de estructuras bidimensionales |
| 🟥 `recursion`     | Resolución de problemas mediante funciones recursivas   |
